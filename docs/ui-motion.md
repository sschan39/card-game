# 動效與座位視覺規範

本檔記錄 2026-11-17 這批 UI 調整的參數與理由。所有動效都必須在
`prefers-reduced-motion: reduce` 下完全關閉。

## 曲線與時長

| 用途 | 時長 | 曲線 |
|---|---|---|
| 面板／頁籤切換 | 200ms | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 卡牌網格逐格入場 | 220ms | `cubic-bezier(0.34, 1.56, 0.64, 1)`（easeOutBack） |
| 開局發牌 | 660ms | `cubic-bezier(0.2, 0.85, 0.3, 1)` |

## 牌組工作坊頁籤

`.deck-panel` 只做 `opacity` 與 `translateY(4px)` 過渡，**不設 `min-height`**。
固定高度下限會讓面板在內容完成佈局前先佔滿該高度，看起來就是「先閃出一個高盒子再縮回」。
高度一律由內容決定。

卡牌網格的 `tile-in` 逐格動畫刻意壓到 220ms／單格延遲 22ms（上限 220ms）：
切換頁籤時網格會重建，較長的逐格彈出會被讀成卡頓。

## 座位膠囊

`.seat-head` 是 999px 膠囊：左側 32px 頭像圓（`::before`，徑向漸層 `#35513d → #16241c`
＋`rgba(125,101,41,.6)` 邊），右側兩行（名稱 11px／字距 `.12em`／`#9fb3a5`，
生命值 14px／700／`#f0e2b6`）。DOM 未改動——既有的 `.life-seal` 直接當頭像用，
所以玩家與對手兩個座位共用同一套規則。

## 開局發牌

`GameScreen` 在 `room.status` 首次變成 `playing` 時掛上 `data-deal="on"`，1400ms 後移除：

1. 對手座位 `.55s`，延遲 `.25s`
2. 階段條 `.6s`，延遲 `.15s`
3. 我方座位 `.5s`，延遲 `.35s`
4. 手牌逐張 `dealFly`，延遲 `calc(var(--i) * 55ms + 300ms)`

`dealFly` 的 100% 幀**故意不寫 `transform`**：動畫結束後要落回手牌自己的內聯扇形變換，
寫死 `translate(0,0) scale(1)` 會把手牌攤平。

只播一次：切換語言或重連不會改變 `status`，因此不會重播。

## 已知限制

- 牌組列表項目的 hover 只改顏色與邊框，沒有位移；若日後加上位移，需同步提高
  `z-index`，否則會被相鄰項的邊框壓住。
- 卡牌網格 `article:hover` 已加 `position: relative; z-index: 1`，上浮 4px 不會被遮擋。
