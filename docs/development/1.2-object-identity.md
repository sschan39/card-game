# 1.2 — Object identity and zone transitions

Status: Implemented stable physical UUID plus zoneRevision.

Inspected source baseline: `ad6a96e`, 12 October 2026. [Development index](README.md). Source inspection documents current structure; test paths below identify verification responsibilities, not a new passing run.

## Purpose

Retain the logical card instance while invalidating references to its earlier zone incarnation.

## Current structure

- `src/engine/zone-transitions.ts` — createCardState, resetCardForZone, getCardInZone and moveCard.
- `src/types/card.types.ts` — CardState.zoneRevision and retained snapshots.
- `src/engine/source-information.ts` — pre-departure characteristic/source snapshots.
- `src/shared/target-legality.ts` — exact reference lookup/legality.

Real moves reset active state from the blueprint and increment zoneRevision; UUID and immutable blueprint remain stable. Reducer copies preserve logical identity. Last-known information belongs to explicit snapshots, not stale live state. Same-zone movement is not a new incarnation.

## Flow

```text
Exact origin lookup → validate complete move → capture departure → reset active state → move atomically → invalidate old references
```

## Extension boundary

New zones require occupant storage, lookup, reducer, choices, events and sync together. Tokens and stack abilities have different occupant/lifecycle rules. 8.1 owns in-place ordering without fake zone changes.

## Remaining work and modification notes

Keep all new target/host/combat/effect references revision-aware. Do not infer that a matching UUID proves the original object returned.

## Acceptance evidence

- tests/engine/zone-transitions.test.ts proves atomicity, reset, persistent UUID and stack occupant rules.
- tests/engine/source-information.test.ts and tests/engine/target-groups.test.ts prove retained information and stale-reference behavior.

## Stop condition

Stop if ordinary movement creates a new physical UUID, preserves stale active counters/attachments, or uses an old instance as live state to avoid capture.
