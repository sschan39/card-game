# 6.1 — Resolved effect lifetime and recipient identity

Status: implemented independent resolved effects and explicit source dependencies. Inspected at `60e9349`, 12 October 2026. [Development index](README.md).

## Purpose and structure

A temporary resolved buff can survive source departure. Its affected objects and its lifetime are separate contracts.

| Module | Owns |
|---|---|
| `src/types/continuous-effect.types.ts` | Entry origin, duration, required zone, source revision/controller and scope |
| `src/engine/continuous-effects.ts` | `normalizeContinuousEntry`, `effectSource`, `effectIsActive`, `scopeMatches` |
| `src/engine/effect-registry.ts` | Generic creation/stat primitives |
| `src/engine/game-reducer.ts` | Entry insertion, exact removal and end-of-turn expiry |
| `src/engine/game-engine.ts` | Remove expired dependent entries on source movement |

Resolved characteristic effects freeze UUID/revision recipients and numeric count expressions at creation. Their source controller is captured independently. `origin: resolved` defaults to `requiredZone: null`; source departure does not cancel an independent effect. Explicit `WHILE_ON_BATTLEFIELD`/`WHILE_ATTACHED` lifetimes require the original battlefield source. Generic creation defaults to permanent; existing `GRANT_STATS` remains explicitly end-of-turn.

## Flow

```text
Resolving effect → normalize identity/controller/recipients/expressions
 → commit entry → effective queries while active
 → duration or explicit dependency expires → remove exact entry
```

## Extension boundary and remaining work

Resolved permission rules intentionally retain dynamic scopes because they alter game rules. Static scopes are dynamic too; do not apply the frozen-recipient policy globally. New durations need serializable definitions and one expiry/query path. `WHILE_ATTACHED` currently tests card attachment state; richer player attachments/family mechanics must revisit that contract under 8.2.

## Acceptance evidence

`tests/engine/continuous-lifetime.test.ts` proves frozen scope, source independence, source-dependent reentry, expression capture and exact expiry/delta replay. `tests/engine/source-information.test.ts` proves returned targets do not regain old buffs. Socket resolved/static lifetime cases are in `tests/server/live-routing.test.ts`.

## Stop condition

Stop if duration is inferred solely from source presence, target UUIDs rebind after revision changes, or removing one entry removes unrelated same-source effects.
