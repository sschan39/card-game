# Minimal announcement bindings — implementation plan

Owner approved Slice B on 12 October 2026 with the instruction to keep it minimal. Execute inline in the existing `codex/milestone-0` checkout.

## Scope

Implement declarations for spells and ordinary activated abilities, scalar prompts through the existing ChoicePanel, binding-only generic mana costs, top-level numeric effect parameters, and retained stack bindings. Reuse the shared numeric evaluator and current payment/target/resolution planners. Keep source incarnation and effective announcement definition stable across prompts. Cancellation restarts an announcement. No settings, catalog additions, variable cardinalities/divisions, nested stat-operation bindings, new conditions, or inheritance into triggered/static/entry effects.

The full [Slice B design](8.4-announcement-bindings.md) remains an extension map; this approved minimal scope supersedes its broader proposed implementation scope.
