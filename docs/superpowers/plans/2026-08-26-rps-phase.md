# RPS Phase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the Rock-Paper-Scissors phase end-to-end so both players choose a card, the server resolves who goes first, and the game transitions to `stateTurnStart`.

**Architecture:** A lightweight `rpsPlay` action handler validates and proposes two mutations (`SET_RPS_PLAYED_CARD` + `MOVE_CARD` hand→graveyard). The `server.ts` `playerAction` switch calls the handler, then checks if both players have played; if so it calls a new pure `resolveRPS(room)` in `room-factory.ts` that returns `SET_RPS_STATUS`/`SET_TURN`/`SET_PHASE` plus `MOVE_CARD` mutations for the remaining RPS cards. Choices are public — no sync-service redaction. The client emits `rpsPlay` during the RPS phase and shows "Waiting for opponent…" derived from `rpsState.playedCards`.

**Tech Stack:** TypeScript, Express + Socket.IO, Zustand 5, React 19, Vitest.

## Global Constraints

- Server is CommonJS (`module: commonjs`); server compiles via `tsc` → `dist/`, client via `vite build` → `dist/client`.
- All state changes flow through the pure `gameReducer(state, mutation) => newState`; handlers never mutate `GameRoom` directly.
- RPS choices are **public** — no privacy redaction in `sync-service.ts`.
- RPS is a vertical slice coupled across ~12 active files (see spec §9). The **new** logic in this plan (handler + `resolveRPS` + server case + client wiring) is additive and isolated to 2 new files + 2 server touchpoints + 2 client components. Do not refactor the pre-existing coupling (`rpsState` field, RPS mutations, `RPS` phase, `end-turn` guard, sync delta cases) — leave them as-is.
- Deck-building does not exist; decks are always empty. Starting-hand dealing is **deferred** — do not implement it.
- Tie rule: player1 goes first on a tie (deterministic, no replayed rounds).
- Beats map: `{ rock: 'scissors', scissors: 'paper', paper: 'rock' }`.
- RPS card blueprint ids: `'rock'`, `'paper'`, `'scissors'`.
- `ActionType = string` — `'rpsPlay'` is a valid action type with no type change needed.

export function setupRPS(room: GameRoom): void {
    room.currentPhase = 'RPS';

    if (!room.player2Id) return;

    const p1 = room.players[room.player1Id];

    room.battlefield = [];

      c2.state.ownerId = room.player2Id;

// src/engine/handlers/rps-play-handler.ts
import type { ActionHandler, ActionData, ActionResult } from '../action-registry';
import type { GameRoom, PlayerId } from '../../types/game.room.types';
import type { StackObject } from '../../types/effect.types';

const RPS_CARD_IDS = ['rock', 'paper', 'scissors'];

/**
 * Play a Rock-Paper-Scissors card during the RPS phase.
 *
 * This is a simultaneous choice with no response window, so it bypasses the
 * normal priority/stack pipeline (which requires priorityPlayerId, null during
 * RPS). It still exercises the mutation/reducer/delta pipeline.
 */
export const rpsPlayHandler: ActionHandler = {
  validate(room: GameRoom, playerId: PlayerId, action: ActionData): ActionResult {
    if (room.currentPhase !== 'RPS') {
      return { success: false, phase: 'validate', reason: 'Not in RPS phase' };
    }
    if (!action.cardUuid) {
      return { success: false, phase: 'validate', reason: 'cardUuid required' };
    }
    const card = room.players[playerId]?.hand.find(c => c.uuid === action.cardUuid);
    if (!card) {
      return { success: false, phase: 'validate', reason: 'Card not in hand' };
    }
    if (room.rpsState.playedCards[playerId]) {
      return { success: false, phase: 'validate', reason: 'Already played' };
    }
    if (!RPS_CARD_IDS.includes(card.blueprint.id)) {
      return { success: false, phase: 'validate', reason: 'Not an RPS card' };
    }
    return { success: true };
  },

  propose(room: GameRoom, playerId: PlayerId, action: ActionData): ActionResult {
    const card = room.players[playerId]?.hand.find(c => c.uuid === action.cardUuid);
    if (!card) {
      return { success: false, phase: 'propose', reason: 'Card not in hand' };
    }
    return {
      success: true,
      mutations: [
        { type: 'SET_RPS_PLAYED_CARD', playerId, card: card.blueprint.id },
        { type: 'MOVE_CARD', cardUuid: card.uuid, playerId, from: 'hand', to: 'graveyard' },
      ],
    };
  },

  resolve(_room: GameRoom, _stackObj: StackObject): ActionResult {
    return { success: true };
  },
};
```

/**
 * Resolve the RPS phase once both players have chosen.
 * Returns mutations that set the winner's turn, transition to stateTurnStart,
 * and discard all remaining RPS cards from both hands.
 *
 * Tie rule: player1 goes first on a tie (deterministic, no replayed rounds).
 * Starting-hand dealing is deferred until deck-building exists (decks are empty).
 */
export function resolveRPS(room: GameRoom): GameMutation[] {
  const p1 = room.player1Id;
  const p2 = room.player2Id!;
  const c1 = room.rpsState.playedCards[p1];
  const c2 = room.rpsState.playedCards[p2];

  // rock > scissors, scissors > paper, paper > rock
  const beats: Record<string, string> = { rock: 'scissors', scissors: 'paper', paper: 'rock' };

  let winner: PlayerId;
  if (c1 === c2) {
    winner = p1; // tie → player1 goes first
  } else if (beats[c1] === c2) {
    winner = p1;
  } else {
    winner = p2;
  }

  const mutations: GameMutation[] = [
    { type: 'SET_RPS_STATUS', status: 'resolved' },
    { type: 'SET_TURN', playerId: winner },
    { type: 'SET_PHASE', phase: 'stateTurnStart' },
  ];

  // Discard remaining RPS cards from both hands
  for (const [pid, player] of Object.entries(room.players)) {
    for (const card of player.hand) {
      if (['rock', 'paper', 'scissors'].includes(card.blueprint.id)) {
        mutations.push({ type: 'MOVE_CARD', cardUuid: card.uuid, playerId: pid as PlayerId, from: 'hand', to: 'graveyard' });
      }
    }
  }

  return mutations;
}
```

- Modify: `src/client/components/PhaseBar.tsx`
- Modify: `src/client/store/gameStore.ts` (add a selector)

**Interfaces:**
- Consumes: `useGameStore`, `selectMyPlayerId`, `selectOpponentId`, `selectCurrentPhase` from `../store/gameStore`.
- Produces: `selectRpsWaitingForOpponent(state): boolean` — true when phase is RPS, my choice is set, and opponent's choice is not set.

**Context:** After a player plays their RPS card, they should see "Waiting for opponent…" until the opponent also plays. This is derived purely from `rpsState.playedCards` — no server involvement. Choices are public, so once the opponent plays, their choice arrives via `stateDelta` and the waiting message disappears.

- [ ] **Step 1: Add the selector**

In `src/client/store/gameStore.ts`, add after `selectCurrentPhase`:

```typescript
export function selectRpsWaitingForOpponent(state: GameStore): boolean {
  const { room, myPlayerId } = state;
  if (!room || !myPlayerId) return false;
  if (room.currentPhase !== 'RPS') return false;
  const opponentId = selectOpponentId(state);
  if (!opponentId) return false;
  const myChoice = room.rpsState.playedCards[myPlayerId];
  const oppChoice = room.rpsState.playedCards[opponentId];
  return Boolean(myChoice) && !oppChoice;
}
```

- [ ] **Step 2: Render the waiting message**

In `src/client/components/PhaseBar.tsx`, import the selector and render the message:

```typescript
import { useGameStore, selectCurrentPhase, selectIsMyTurn, selectRpsWaitingForOpponent } from '../store/gameStore';
import { useGameActions } from '../hooks/useGameActions';

export default function PhaseBar() {
  const phase = useGameStore(selectCurrentPhase);
  const isMyTurn = useGameStore(selectIsMyTurn);
  const waitingForOpponent = useGameStore(selectRpsWaitingForOpponent);
  const { playerAction } = useGameActions();

  return (
    <div className="phase-bar">
      <p>Phase: <strong>{phase ?? '—'}</strong></p>
      {waitingForOpponent && <p className="rps-waiting">Waiting for opponent…</p>}
      {isMyTurn && phase !== 'RPS' && (
        <div className="phase-actions">
          <button onClick={() => playerAction('end_turn')}>End Turn</button>
          <button onClick={() => playerAction('pass_priority')}>Pass Priority</button>
          <button onClick={() => playerAction('resolve_stack')}>Resolve Stack</button>
        </div>
      )}
    </div>
  );
}
```
